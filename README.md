# 🏸 Smash Badminton 3D - AI機器人 羽球練習中心

一個基於 3D 視覺與物理機制的網頁羽球練習遊戲，支援第一人稱與第三人稱切換、甜區 timing 擊球機制及 AI 拋高遠球對戰功能。

---

## ✨ 遊戲特色

* **🎥 雙視角切換：** 支援第三人稱與第一人稱視角自由切換（按 `V` 鍵）[cite: 1]。
* **🎯 甜區 Timing 擊球機制：** 具備發力甜區（Sweet Spot）條，考驗玩家時機掌握度[cite: 1]。
* **🤖 AI 拋球與對戰系統：** 自動拋出高遠球與機器人進行連續來回對戰[cite: 1]。
* **💰 獎勵機制：** 殺球落入對手界內可獲得金幣獎勵[cite: 1]。

---

## 🕹️ 遊戲操作與控制

| 按鍵 / 控制方式 | 功能說明 |
| :--- | :--- |
| **`W` / `A` / `S` / `D`** | 控制角色在場地上的步走位[cite: 1] |
| **滑鼠移動** | 瞄準視角落點與壓低瞄準[cite: 1] |
| **滑鼠點擊** | 在甜區 Timing 進行揮拍擊球[cite: 1] |
| **`Space` (空白鍵)** | 跳躍（空中擊球即可進行跳殺）[cite: 1] |
| **`F` 鍵** | 一鍵跳殺[cite: 1] |
| **`R` 鍵** | 前空翻自動救球[cite: 1] |
| **準心上抬** | 打高遠球[cite: 1] |
| **`V` 鍵** | 切換第一人稱 / 第三人稱視角[cite: 1] |

---

## 🚀 如何執行

1. 下載本專案所有檔案。
2. 直接點擊 `program.html` 即可在任何支援 WebGL 的主流瀏覽器（Chrome, Edge, Firefox 等）中開啟並進行遊戲！

---

## 🛠️ 開發技術

* **前端架構：** HTML5, CSS3, JavaScript (ES6+)
